# SARD - Simple Azure Resource Deployment

This module is used to deploy a large number of Azure resources into a single resource group. This is more a proof of concept, that deploys a large number of cheap resources for investigation and learning, before deplying them in a more traditional way. But, there are many option, you can add Private EndPoint and choose inbound access options, such as 'None' or 'FrontDoor' or 'App-Gateway', whilst also choosing to integrating with an accessing Azure vWAN and Secure Hub (Azure Firewall), for managing outbound access.

It can be though of as a poor-person's Azure Landing Zone, since it only does not need multiple scriptions or managements groups etc...

## Features

- Simple
- Easy
- Great for reviewing the capability of individual Azure resources.
- Has options to integration Azure vWANs  / Secure Hubs for exsting environments if required.
